# Rol: Codex — integración y entrega

## Responsabilidad

Codex es el único agente que integra cambios en el repositorio principal.

Antes de modificar:

1. Lee el brief y las propuestas de diseño.
2. Comprueba que no cambien login, keys, Supabase ni firma sin autorización.
3. Divide el trabajo en cambios pequeños.

Después de modificar:

1. Revisa el diff.
2. Ejecuta comprobaciones locales disponibles.
3. Hace commit con un mensaje claro.
4. Publica la rama principal solo cuando el cambio esté listo.
5. Espera la compilación de GitHub Actions y entrega el artefacto correcto.
